# StyleRewriter

Django-приложение для переписывания текста в стиле различных персонажей.

## Описание

StyleRewriter позволяет пользователям переписывать текст в стиле выбранного персонажа. Приложение поддерживает анонимных пользователей и зарегистрированных пользователей, сохраняет историю запросов и готово к интеграции с LLM API.

## Требования

- Python 3.10+
- Django 5.x (или 6.x)
- SQLite (для MVP)
- Интернет-соединение (для работы бесплатного ИИ через g4f)

## Установка и запуск

1. **Активируйте виртуальное окружение** (если еще не активировано):
   ```bash
   # Windows
   venv\Scripts\activate
   
   # Linux/Mac
   source venv/bin/activate
   ```

2. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```
   Или установите вручную:
   ```bash
   pip install django g4f
   ```

3. **Создайте новых персонажей с блогерами и корейскими айдолами**:
   ```bash
   python manage.py create_new_personas
   ```
   Эта команда создаст новых персонажей (российские и иностранные блогеры, корейские айдолы) и заменит старых.
   
   Для сохранения старых персонажей используйте:
   ```bash
   python manage.py create_new_personas --keep-old
   ```
   
4. **Скачайте изображения для персонажей** (опционально):
   ```bash
   python manage.py download_persona_images
   ```
   Эта команда попытается скачать изображения из интернета.
   
   Или вручную добавьте изображения в папку `photos` и запустите:
   ```bash
   python manage.py assign_images_from_photos
   ```
   Эта команда автоматически присвоит изображения из папки photos персонажам по совпадению имени.

5. **Примените миграции**:
   ```bash
   python manage.py makemigrations
   python manage.py migrate
   ```

6. **Создайте суперпользователя для доступа к админке**:
   ```bash
   python manage.py createsuperuser
   ```

7. **Запустите сервер разработки**:
   ```bash
   python manage.py runserver
   ```

5. Откройте браузер и перейдите по адресу: `http://127.0.0.1:8000/`

## Модели

### Persona
- `name` - Имя персонажа (уникальное)
- `style_description` - Описание стиля переписывания
- `created_at` - Дата создания
- `updated_at` - Дата обновления

### RewriteRequest
- `user` - Пользователь (может быть null для анонимных)
- `original_text` - Оригинальный текст
- `persona` - Выбранная персона
- `rewritten_text` - Переписанный текст
- `created_at` - Дата создания запроса

## Функционал

### Главная страница (`/`)
- Главное меню с кнопкой для перехода к списку персонажей
- После выбора персонажа - форма для общения в его стиле
- Выбор типа сообщения: Своя фраза, Подкат, Поздравление, Шутка
- Отображение результата переписывания
- Работает для анонимных и зарегистрированных пользователей

### Список персонажей (`/personas/`)
- Карточки всех доступных персонажей
- Сворачиваемое/разворачиваемое описание каждого персонажа
- Кнопка "Выбрать" для выбора персонажа
- После выбора - автоматический переход на главную страницу

### Аутентификация
- Регистрация: `/accounts/register/`
- Вход: `/accounts/login/`
- Выход: `/accounts/logout/`

### Админка (`/admin/`)
- Управление персонами (создание, редактирование, удаление)
- Просмотр истории всех запросов на переписывание
- Фильтрация и поиск по запросам

## ИИ-интеграция

Приложение использует **бесплатную библиотеку g4f** для переписывания текста в стиле выбранной персоны.

### Как это работает:

1. Пользователь вводит текст и выбирает персону
2. Система формирует промпт на основе описания стиля персоны
3. Библиотека g4f предоставляет бесплатный доступ к GPT моделям через различные провайдеры
4. ИИ переписывает текст в указанном стиле
5. Результат сохраняется в базу данных

### Преимущества:

- ✅ **Полностью бесплатно** - не требуется API ключ
- ✅ **Несколько моделей** - автоматический перебор моделей при ошибках
- ✅ **Простая настройка** - просто установите библиотеку
- ✅ **Обработка ошибок** - понятные сообщения при проблемах

### Настройка:

- Никаких API ключей не требуется!
- Используются модели: `gpt-3.5-turbo`, `gpt-4`, `gpt-4o-mini`
- При ошибке одной модели автоматически пробуется следующая
- Обработка ошибок: при проблемах с API пользователь увидит понятное сообщение

### Файлы:

- `style_rewriter/ai_service.py` - сервис для работы с g4f
- `style_rewriter/views.py` - использует `rewrite_text_with_ai()` для переписывания

### Примечание:

Библиотека g4f использует неофициальные API и может быть нестабильной. Для продакшена рекомендуется использовать официальные API (OpenAI, Anthropic и т.д.).

## Настройки

Основные настройки в `persona_talker/settings.py`:
- `LANGUAGE_CODE = 'ru-ru'` - Русский язык
- `TIME_ZONE = 'Europe/Moscow'` - Московское время
- `LOGIN_REDIRECT_URL = 'home'` - Редирект после входа
- `LOGOUT_REDIRECT_URL = 'home'` - Редирект после выхода

## Статические файлы

Статические файлы настроены, но для продакшена может потребоваться дополнительная настройка через `collectstatic`.

## Примечания

- Все запросы сохраняются в базу данных, даже от анонимных пользователей
- Миграции созданы, но не применены (нужно выполнить `makemigrations` и `migrate`)
- UI минималистичный, без внешних CSS-фреймворков (только inline-стили)
