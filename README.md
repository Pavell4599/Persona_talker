# Persona Talker 🎭

Django-приложение для переписывания текста в стиле различных персонажей с красивым интерфейсом в стиле мессенджера.

## Описание

Persona Talker позволяет пользователям переписывать текст в стиле выбранного персонажа. Приложение содержит 122 персонажа из разных категорий: блогеры, актеры, айдолы, поп-артисты, ученые, комики, политики и мемы.

## Особенности

- 🎨 **Красивый UI** - интерфейс в стиле мессенджера с аватарами персонажей
- 🎭 **122 персонажа** - блогеры, актеры, айдолы, поп-артисты, ученые, комики, политики, мемы
- 💬 **Типы сообщений** - Подкат, Поздравление, Шутка или своя фраза
- 🤖 **ИИ-переписывание** - использует бесплатную библиотеку g4f
- 📱 **Адаптивный дизайн** - работает на всех устройствах

## Требования

- Python 3.10+
- Django 6.0
- SQLite
- Интернет-соединение (для работы бесплатного ИИ через g4f)

## Установка и запуск

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/Pavell4599/Persona_talker.git
   cd Persona_talker
   ```

2. **Активируйте виртуальное окружение**:
   ```bash
   # Windows
   venv\Scripts\activate
   
   # Linux/Mac
   source venv/bin/activate
   ```

3. **Установите зависимости**:
   ```bash
   cd persona_talker
   pip install -r requirements.txt
   ```

4. **Создайте персонажей**:
   ```bash
   python create_100_personas.py
   python create_all_images.py
   ```

5. **Примените миграции**:
   ```bash
   python manage.py makemigrations
   python manage.py migrate
   ```

6. **Создайте суперпользователя**:
   ```bash
   python manage.py createsuperuser
   ```

7. **Запустите сервер**:
   ```bash
   python manage.py runserver
   ```

8. Откройте браузер: `http://127.0.0.1:8000/`

## Использование

1. Выберите персонажа из списка
2. Выберите тип сообщения (Подкат, Поздравление, Шутка или своя фраза)
3. Введите текст (или оставьте пустым для автоматической генерации)
4. Получите результат в стиле выбранного персонажа!
