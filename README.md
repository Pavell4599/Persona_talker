# Persona Talker 🎭

Django-приложение для переписывания текста в стиле различных персонажей с использованием ИИ.

## Описание

Persona Talker позволяет пользователям переписывать любой текст в стиле выбранного персонажа. Приложение содержит более 100 персонажей из разных категорий: блогеры, актеры, айдолы, поп-артисты, ученые, комики, политики и мемы.

## Основные возможности

- 🎭 **100+ персонажей** из разных категорий
- 💬 **Интерфейс в стиле мессенджера** с аватарами персонажей
- 🤖 **ИИ-переписывание** текста в стиле выбранного персонажа
- 📝 **Типы сообщений**: Своя фраза, Подкат, Поздравление, Шутка
- 🎨 **Современный UI** с градиентами и анимациями

## Требования

- Python 3.10+
- Django 6.0
- SQLite
- Интернет-соединение (для работы бесплатного ИИ через g4f)

## Установка и запуск

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/Pavell4599/Persona_talker.git
   cd Persona_talker
   ```

2. **Создайте виртуальное окружение**:
   ```bash
   # Windows
   python -m venv venv
   venv\Scripts\activate
   
   # Linux/Mac
   python3 -m venv venv
   source venv/bin/activate
   ```

3. **Установите зависимости**:
   ```bash
   cd persona_talker
   pip install -r requirements.txt
   ```

4. **Примените миграции**:
   ```bash
   python manage.py migrate
   ```

5. **Создайте персонажей**:
   ```bash
   python create_100_personas.py
   python create_all_images.py
   ```
   (Из корня проекта)

6. **Запустите сервер**:
   ```bash
   python manage.py runserver
   ```

7. Откройте браузер и перейдите по адресу: `http://127.0.0.1:8000/`
